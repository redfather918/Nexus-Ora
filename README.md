# Nexus Ora — AI 原生玄学平台 MVP

人生 K 线 · 用东方命理 × AI 预测你的人生运势曲线

License: MIT Node.js Pure JS

✨ 核心特性
🔮 精准八字排盘 — 基于 lunar-typescript 开源库，纯 JS 实现，年月日时四柱精确计算
📈 人生 K 线可视化 — ECharts 折线图，中国股市红涨绿跌惯例
🤖 AI 运势解读 — DeepSeek LLM 预测 0-100 岁运势曲线 + 六维度深度分析
🔊 算法回退 — 无 AI Key 时自动使用五行生克 / 群体涌现算法，离线完整可用
💾 本地数据持久化 — sql.js (WASM SQLite)，无需安装数据库
🌐 零配置启动 — 无需 Python、无需 API Key，一条命令即可运行

### 模块亮点

- **灵境图谱（Module 1）** — 输入出生时空即得四柱八字、五行平衡、十神格局、身强身弱，以及贯穿 0-100 岁的「命运 K 线」（101 采样点，红涨绿跌）。六维解读（事业/财运/感情/健康/贵人/挑战）输出 1-95 评分与可执行建议。
- **灵境人格（Module 2）** — 基于日主五德 + 十神映射生成「灵魂伴侣式」虚拟人格，注入系统 prompt 进行日常对话、情绪支持与轻量命理解读；对话历史本地留存 50 轮，可一键重置。
- **梦境回廊（Module 3）** — 文字记录梦境，双维度（周公解梦 + 现代心理学）解析 + 趋势可视化，AI 周报自动生成。
- **缘分配对（Module 4）** — 双人八字合盘，五行生克 + 十神配合 + 日柱六合六冲，输出五维雷达评分与「关系画像」（天作之合 / 五行相生 / 欢喜冤家等）。
- **灵境占卜（Module 5）** — 78 张韦特塔罗（单牌 / 三牌 / 凯尔特十字）、摇杯筊三圣杯问卜、100 支古典每日一签（按日 hash 稳定）。
- **灵境修行（Module 6）** — 了凡四训打卡（5 段修行等级 + streak）、5 场景冥想引导、能量日记（7/30/90 天情绪趋势）。
- **灵境市集（Module 7）** — 数字周边（PDF/PNG 报告）、水晶商城（五行 → 日主适配映射）、线下活动 O2O 报名留资。
- **紫微斗数（Module 8）** — 安十二宫 + 十四主星 + 生年四化；**钦天四化（北派飞星）** 来因宫 + 生年四化落宫 + 十二宫宫干飞星（48 条轨迹）+ 离心/向心自化，与三合格局交叉验证。
- **灵境数测（Module 9）** — 数字能量学「八星」算法，手机号/车牌/电动车牌纯算法测算，自带分享钩子，利于社交传播。

## 🤖 推演引擎（v5.2 重构）

借鉴开源 **MiroFish**「多智能体群体智能 + 平行世界」理念，将原本单次公式 / 单次 LLM 调用，升级为三层推演架构：

- **多智能体议会解读（Agent Council）** — 盘师（格局 / 喜用神）+ 运师（大运 / 转折点）+ 世师（现实策略）三智能体并行，主笔人（Narrator）仲裁汇总；无 API Key 自动降级为群体涌现算法。
- **群体涌现运势算法（Swarm Fortune）** — 六大因子代理（生命周期 / 五行 / 大运 / 流年 / 十神 / 日主平衡）加权共识 + 分歧度扰动，生成更真实的命运 K 线（替代原单公式回退）。
- **人生沙盘推演（Life Sandbox）** — 本我 + 进取 / 稳健 / 转型 平行世界线，可注入人生干预（如「30 岁创业」）观察轨迹分叉，输出推荐世界线与 AI 结论。
- **前端可视化** — 「引擎透视」面板（智能体视角 Tab + 因子共识图 Tab，推演动画化）、「人生沙盘推演」面板（推演剧场 + 世界线生长 + 流式结论）。

## 🚀 快速开始

### 一条命令启动

```bash
cd backend
npm install
node server_unified.js
# 浏览器打开 http://127.0.0.1:3000
```

> **无需 Python！** 排盘引擎已完全 JavaScript 化（lunar-typescript），不再需要 Python 环境。

### 配置 AI 增强（可选）

```bash
cp .env.example .env
# 编辑 .env，填入 DEEPSEEK_API_KEY（不填则使用算法模式）
```

### 其他入口

- **微信小程序** — `miniprogram/` 目录，11 页面原生小程序，生产域名 `life.p1web.site`。
- **分享卡片** — `frontend/share_cards.html` 独立页面静态展示 9 张 9:16 竖版分享卡；或在测算结果页点击「生成分享图」动态生成（含可配置域名二维码）。

## ⚙️ 环境变量

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `PORT` | 服务器端口 | `3000` |
| `DEEPSEEK_API_KEY` | DeepSeek API Key（可选） | 空（算法模式） |
| `STRIPE_SECRET_KEY` | Stripe 私钥（可选） | 空（Demo 模式） |
| `PAYPAL_*` | PayPal 收款配置（可选） | 空（Demo 模式） |
| `UNLOCK_FULL_REPORT` | 推广模式：true 时完整报告对所有人免费 | `false` |
| `SHARE_URL` | 分享图二维码域名（留空回退当前域名） | 空 |

## 📊 运势颜色规则

遵循**中国股市惯例**（与欧美色系相反）：
- 🔴 **红色** = 运势上涨（大吉 / 小吉）
- 🟢 **绿色** = 运势下跌（大凶 / 小凶）
- ⚪ **灰色** = 平稳
